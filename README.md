# RelationGraph Web（相関図メーカー）

[日本語](#日本語) | [English](#english)

---

## 日本語

人物・組織の相関図を作成できるWebツールです。インストール不要で、PC・スマホの両方で使えます。

すべての処理はお使いの端末内で行われます。作成したデータや画像がどこかに送信されることはありません。

**👉 [今すぐ使う](https://daigorou-addon.github.io/relation-graph-web/)**

Windows向けのデスクトップ版もあります: [RelationGraph（デスクトップ版）](https://github.com/daigorou-addon/RelationGraph/releases)

### 主な機能

- **ノード**: 名前とサブ（役割など）を設定。スタイルはカード型 / コンパクトカード / シンプル枠 / 丸から選べます
- **画像**: ノードに写真を設定（キャンバスへのドラッグ＆ドロップ、またはスマホでは画像を選択）。トリミング、位置・スケール調整、角丸／丸のクリップに対応
- **接続線**: 実線 / 破線 / 点線 / 二重線 / 直角折れ線、矢印（片方向・双方向・塗り・丸・ダイヤ・バー）。太さ・色・ラベル（テキスト・サイズ・色・形・角度）を設定可能
- **枝分かれ接続・フォーク接続（1対多）**: 1つのノードから複数のノードへまとめて接続
- **テキスト**: 自由に配置できるテキスト（フォント・サイズ・色・太字・枠・背景色と透明度）
- **グループ**: 複数のノードを囲むグループ（ラベル・塗り色・枠色・形状・透明度・枠スタイル）
- **背景色の変更**
- **Undo**（元に戻す）
- **保存・読み込み**: プロジェクトを `.rg` ファイルとして保存して、あとで開けます
- **画像出力**: PNG / SVG
- **スマホ対応**: 長押しメニュー、ピンチで拡大縮小、2本指でドラッグ移動
- **6言語対応**（日本語 / English / 한국어 / 简体中文 / 繁體中文 / Español）

### 基本操作（PC）

| 操作 | 方法 |
| --- | --- |
| ノード追加 | 「ノード」→キャンバスをクリック |
| 接続 | ノードにホバー→右上のボタン |
| 画像設定 | キャンバスに画像をドラッグ＆ドロップ |
| ズーム | マウスホイール |
| 画面移動 | スペース＋ドラッグ または 中ボタン |
| 削除 | 選択して Delete キー |
| Undo | Ctrl+Z |
| 保存 / 開く | Ctrl+S / Ctrl+O |
| フォーク接続 | ノードを右クリック →「フォーク接続」→ 子ノードを複数クリック → Enter または「確定」 |

スマホでの操作は、画面内の「使い方」タブで確認できます。

## English

RelationGraph Web is a web tool for creating relationship diagrams of people and organizations. No installation is required, and it works on both desktop and mobile.

Everything is processed on your own device. Your diagrams and images are never sent anywhere.

**👉 [Try it now](https://daigorou-addon.github.io/relation-graph-web/)**

A desktop version for Windows is also available: [RelationGraph (desktop version)](https://github.com/daigorou-addon/RelationGraph/releases)

### Features

- **Nodes**: set a name and a sub line (such as a role). Choose a style: card, compact card, simple frame, or circle
- **Images**: set a photo on a node (drag and drop onto the canvas, or pick an image on mobile). Supports cropping, position/scale adjustment, and rounded-rectangle or circle clipping
- **Connection lines**: solid / dashed / dotted / double / elbow lines, and arrows (single, both directions, filled, circle, diamond, bar). Set width, color, and a label (text, size, color, shape, angle)
- **Branch and fork connections (one-to-many)**: connect one node to multiple nodes at once
- **Text**: freely placed text (font, size, color, bold, border, background color and opacity)
- **Groups**: enclose multiple nodes in a group (label, fill color, border color, shape, opacity, border style)
- **Background color**
- **Undo**
- **Save / open**: save your project as an `.rg` file and open it again later
- **Image export**: PNG / SVG
- **Mobile support**: long-press menus, pinch to zoom, two-finger drag to pan
- **6 languages** (日本語 / English / 한국어 / 简体中文 / 繁體中文 / Español)

### Basic controls (desktop)

| Action | How |
| --- | --- |
| Add a node | "Node" → click the canvas |
| Connect | Hover over a node → top-right button |
| Set an image | Drag and drop an image onto the canvas |
| Zoom | Mouse wheel |
| Pan | Space + drag, or middle mouse button |
| Delete | Select, then press Delete |
| Undo | Ctrl+Z |
| Save / Open | Ctrl+S / Ctrl+O |
| Fork connection | Right-click a node → "Fork connection" → click multiple child nodes → press Enter or "Confirm" |

Mobile controls are explained in the "Help" tab inside the app.
